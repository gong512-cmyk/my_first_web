Today I truly launched my own website with Vibe Coding for the first time. I ran into quite a few problems along the way: deployment issues, VPS environment setup, and repeated adjustments to the automation flow. But in the end, I got the site successfully running on my VPS. For me, this was more than just making a page accessible. It was a real shift from understanding and thinking about things to actually building, shipping, and owning the result myself.

Even though the site is now online and the URL works, I can already see that the more important part starts now: learning how to use GitHub for version control properly, making the update process more reliable, continuing to maintain and expand features, and turning operations into a routine I can sustain. I have not fully figured those parts out yet.

So today feels more like a starting point than a finish line. What it marks is not that the website is done, but that I have truly stepped into web coding and website operations.
