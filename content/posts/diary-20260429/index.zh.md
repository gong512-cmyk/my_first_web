今天投入了一整天在语音输入软件的设计与开发上。

从产品需求出发，我考虑了最核心的一点：现有的语音输入软件对本地方言支持几乎是空白，我需要一个能留出模型微调接口的方案。讨论了很久，第一版 PRD 算是成型了。

正准备从头编译时，我意识到这是互联网时代——先去 GitHub 搜一搜。果然找到了 opentypeless 这个开源项目。在它的基础上重新适配功能、重写设计文档，然后用 tmux 在手机上远程操控 Mac mini 完成了前端编译。第一次真正利用开源项目实现本地编译，感受到了开源协作的力量。GitHub 被叫做"第一个实现共产主义的地方"，这话今天有了具体的体感。

晚上，收到 Anthropic 的邮件：Claude 账号被封了。复盘原因，可能是我最近频繁让 Claude 接入国产模型所致。中国人用海外 AI 服务本来就是在夹缝里，封了也罢。国产模型现在已经能胜任大部分任务，是时候全面切换了。

## 关键操作
- 设计语音输入软件产品方案，完成第一版 PRD
- 基于 opentypeless 开源项目重新适配功能，重写设计文档
- 用 tmux 在手机上完成前端编译工作
- 在 GitHub 上开源网页翻译软件项目
- 收到 Claude 账号被封通知，决定切换国产模型
