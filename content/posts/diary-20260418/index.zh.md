今天第一次借助 GitHub Copilot 的自主编程能力，做了一个记录运动的 App。Vibe Coding 时代，干中学、学中干，先干再说。

---

## 碎片想法

- Vibe Coding 时代，更适合干中学、学中干。
- 很多问题不是先想明白才有答案，而是先做起来，答案会在过程中出现。
- "先干再说"正在变成一种更有效的行动方式。
- 以前更多是程序员才能完成的事，现在普通非专业人士也能借助 AI 去完成。
- AI 会显著冲击替代性强的行业，但人类的好奇心和欲望未必能被替代。
- 真正值得持续思考的，不只是 AI 能做什么，而是人类还剩下什么是独特的。
- 对 AI 工具的理解，还是要靠实战来验证，纸面理解不等于真正掌握。
- 维护 Obsidian 时，VS Code 不只是写作工具，更像是一个能帮助发现死链接、数据不匹配和知识库结构问题的维护中枢。
- 当 Claude Code 的使用门槛和环境限制变成阻力时，转向更顺手、更稳定的工具链并不算妥协，而是更现实的迭代。

> **AI 点评：** 今天不只是学了一个新工具，而是开始形成自己对 AI 工作流的判断标准：什么值得投入、什么适合长期使用、什么必须靠实战检验。这个转向很务实，也很清醒。
