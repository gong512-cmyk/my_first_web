今天做了几件事，有技术向的，也有管理向的。

先查了 GitHub Copilot 的订阅费用。目前来看，这是对国内用户最友好的平台了——Claude 和 GPT 多模型整合在一起，不用分别订阅，性价比不错，值得持续关注。

然后用 Hermes Agent 搭了一套个人数据库系统。处理资料库确实得心应手，分类、检索、关联都比手动整理高效得多。但做完之后反而更清醒了：框架从来不是核心。工具再好，如果不知道怎么往里面填东西、不知道怎么用这些知识去辅助思考和决策，那就是一个漂亮的空壳。打造第二大脑这件事，框架只是第一步，后面还有大量的细节需要持续打磨——怎么记、怎么整理、怎么回顾、怎么让知识和知识之间产生连接。这是长期功夫，急不来。

工厂那边，今天有两点值得记。一是技术人员遇到困难时，习惯性「眼睛向外」——先看设备问题、流程问题、别人配合的问题，很少先问自己哪里没做到位。这个习惯需要慢慢引导，不是批评一两次能改的，但方向必须坚持。二是 Boss 早会上强调了自动化减少人为操作失误的重要性，已经安排庄玉伟跟进推进。这件事记下来是对的——重要的事不能只靠记性。

## 关键操作

- 调研 GitHub Copilot 订阅方案，确认其为国内用户最优的多模型整合平台
- 使用 Hermes Agent 搭建个人数据库系统，明确「框架是手段，持续经营才是核心」
- 工厂早会：Boss 强调自动化减少人为失误，安排庄玉伟跟进
- 关注技术人员「眼睛向外」的倾向，需长期引导向内归因

## 碎片想法

第二大脑这个词这几年被喊得很多，但大部分讨论都聚焦在「用什么工具」上——Obsidian 还是 Notion，Logseq 还是 Roam。其实工具之争是最不重要的。真正难的是养成「记录—整理—回顾—连接」的习惯闭环。没有这个闭环，再好的工具也只是电子坟场，存了一堆永远不会再打开的笔记。
