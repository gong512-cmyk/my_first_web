# Context

## Canonical terms

- Brand-first homepage: The first screen optimizes identity and personal positioning before showing post lists.
- Content-distribution homepage: The first screen optimizes immediate access to recent posts and categories.
- Hero narrative: The single dominant story block in the first viewport (portrait/visual + name + one-line positioning + primary actions).

## Current decisions

- Homepage mode: Brand-first homepage.
- First-screen structure: Hero narrative first, post feed moved below the fold.
- Hero visual anchor: Real portrait as the dominant first-screen visual.
- Hero copy emphasis: Life tone first, professional context second.
- Visual palette: Replace the current purple-led palette with warm neutrals and one deep green accent.
- Navigation IA: Keep only four primary nav items (Home, Posts, Timeline, About).
- Hero CTA priority: Content-first actions as primary, contact actions as secondary.
- Homepage layout pattern: Two-column hero in first screen, then a content stream section below.
- Portrait treatment: Keep real-photo identity, with light stylistic processing for signature texture.
- Time signal on homepage: Add a lightweight recent-time module directly below hero.
- Typography strategy: Adopt a two-role font system (body/UI and expressive heading font).
- Rollout scope: Redesign homepage first as the canonical visual template.
- Motion policy: No intentional entrance animations; keep interaction mostly static.
- Mobile navigation policy: Remove fixed bottom navigation on mobile.
- Hero visual ratio: Portrait area takes about 40%-45% of first-screen width.
- Time module presentation: Use a compact timeline style below the hero.
- Tag module priority: Deprioritize tags on homepage; keep them in lower sections or posts page.
- Hero background style: Paper-like texture with asymmetric soft color blocks.
- Portrait source: /assets/images/portrait.png (comic-style photo, used as-is initially).
